# pi agent config

My [pi](https://github.com/badlogic/pi-mono) coding-agent home directory
(`~/.pi/agent`): custom extensions, skills, and themes.

A fork of Ben Davis's pi setup, tuned for local inference on a 2x DGX
Spark rig alongside Codex models.

Secrets and machine-specific config (`auth.json`, `models.json`,
`settings.json`, `.env`, sessions) are gitignored — see
[SETUP.md](./SETUP.md) to get it running.
